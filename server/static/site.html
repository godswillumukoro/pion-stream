What This Is

pion-stream is a self-hosted WebRTC streaming server that lets you publish live video from OBS Studio and watch it in any modern browser — no Twitch account, no YouTube channel, no CDN required.

It implements the WHIP (WebRTC-HTTP Ingest Protocol) for publishing and WHEP (WebRTC-HTTP Egress Protocol) for playback. Both are emerging IETF standards designed to make WebRTC streaming as simple as HTTP.

Built entirely on Pion WebRTC, the pure-Go WebRTC implementation. No cgo. No external dependencies. Ships as a single static binary.

Quick Start

Then open http://172.239.127.130 in your browser.

Configuration

All settings are configured via environment variables. Copy .env.example to .env and edit as needed.

Variable Description Default
PORT HTTP server listen port 80
UDP_PORT_MIN Start of ICE UDP candidate port range 3000
UDP_PORT_MAX End of ICE UDP candidate port range 4000
PUBLIC_IP Server public IP for ICE host candidates (auto-detect)
STUN_SERVER STUN server URL for NAT traversal stun:stun.l.google.com:19302
STREAM_KEY Optional bearer token for WHIP auth (none)
